# 시설물 라벨링 툴

드론 항공영상에서 도로안전시설물 3종(도로표지판, 중앙분리대, 무단횡단방지펜스)을
**박스 + 키포인트 4점**으로 라벨링하고, AI 보조로 속도를 높이고, YOLO Pose 데이터셋으로 내보내는 툴입니다.

## 실행

`run.bat` 더블클릭 (conda 환경 `ai_label` 사용)
또는 `python main.py`

### 처음 설치 (PC마다 한 번, Anaconda Prompt)

```
conda create -n ai_label python=3.11 -y
conda activate ai_label
pip install torch==2.11.0 torchvision==0.26.0 --index-url https://download.pytorch.org/whl/cu128
pip install -r requirements.txt
```

- 패키지 목록과 버전: `requirements.txt`
- 깃허브에 없는 것 (`.gitignore`로 제외, 구글 드라이브 등으로 따로 받기)
  - `datasets\` 데이터셋 폴더, `raw_data\` 원본 영상
  - `models\` 안의 AI 가중치 파일 (`.pth`, `.safetensors`, `.pt`, 하나가 100MB 넘음). 받는 곳은 각 폴더의 `_model_info.json`

## 용어
- **데이터셋**: 영상에서 뽑은 이미지 + 라벨 + 학습한 AI 를 모아 둔 폴더 하나 (`datasets\<이름>`). 영상 여러 개를 한 데이터셋에 넣을 수 있습니다.
- **YOLO 데이터셋**: 4번 탭에서 내보낸 팀원 전달용 결과물 (`<데이터셋>\exports\<날짜>`).

## 시작하기
- **이어서 작업하기**: 1번 탭 목록에서 데이터셋 더블클릭
- **새 영상으로 시작하기**: 영상 선택 → 구간 자르기 → 프레임 추출 (새 데이터셋 폴더, 이름 자동) → (3번 탭) 다른 데이터셋 모델 가져오기 → (2번 탭) AI 자동 라벨링 여러 장 → AI 예측 확인 후 확정

## 작업 순서

| 탭 | 하는 일 |
|---|---|
| 1. 데이터셋 / 영상 | 데이터셋 열기, 또는 영상 선택 → 구간 자르기 → 간격(추천 0.5초) → 프레임 추출 (새 데이터셋 폴더). 진행 현황(전체 몇 장 중 사람 검수 몇 장) 확인 |
| 2. 라벨링 | 박스 그리기 → 키포인트 AI 자동 라벨링 (또는 직접 찍기) → 확정(Space). 시설물 없는 이미지는 N. AI 자동 라벨링 여러 장 한 번에. 보기에서 상태별, 클래스별(표지판 / 분리대 / 펜스 있는 이미지) 골라 보기 |
| 3. AI 학습 | 확정한 라벨로 박스 AI + 키포인트 AI 학습 (둘 다 또는 하나만), 여러 데이터셋 함께 학습 (체크), 다른 데이터셋 모델 가져오기 |
| 4. 내보내기 | 사람 검수 완료 이미지만 YOLO Pose 형식으로 (train 증강 포함, 증강 장수, 세기, 옵션 설정 + 미리보기) |
| 5. YOLO 학습 / 추론 | 내보낸 YOLO 데이터셋(data.yaml)으로 YOLO11-pose 학습 → 영상 넣으면 박스, 키포인트 그린 결과 영상 |

### 라벨링 화면에서 AI 쓰기 (오른쪽 'AI 자동 라벨링')
- **박스를 그리면 키포인트 AI 자동 라벨링** (기본 꺼짐, 켜면 동작): 박스를 그리면 키포인트 4개가 바로 찍힙니다. 틀린 키포인트만 끌어서 고치면 됩니다.
- **AI 자동 라벨링: 키포인트만**: 박스만 있고 키포인트가 없는 객체에 키포인트를 찍습니다.
- **AI 자동 라벨링: 박스 + 키포인트**: 현재 이미지 1장에서 박스를 찾고 키포인트까지 찍습니다. 박스 AI까지 학습한 모델에서만 동작합니다.
- **AI 자동 라벨링: 여러 장 한 번에**: 대상(미작업 이미지 전체 / 미작업 + 기존 AI 예측), 박스 threshold 지정 후 시작. 끝나면 보기 'AI 예측'으로 자동 전환.
- 다른 데이터셋에서 학습한 모델은 3번 탭 **다른 데이터셋 모델 가져오기**로 가져옵니다 (`datasets\<데이터셋>\models\<날짜>` 폴더 선택).

### 내보내기 형식 (기존 툴과 호환)
- 라벨 한 줄: `클래스 cx cy w h  x1 y1 v1 ... x4 y4 v4` (0~1 비율, 끝자리 0 제거, 보이는 키포인트 v = 2, 없는 키포인트 `0 0 0`). 기존 툴과 글자 하나까지 같습니다.
- data.yaml: `nc`, `names`, `kpt_shape: [4, 3]`, `flip_idx: [0, 1, 2, 3]`, `kpt_names` (기존 툴과 같은 항목) + `classes.txt`
- 원본 이미지는 다시 압축하지 않고 그대로 복사합니다.
- **클래스 번호** (팀원 모델과 반드시 같아야 함)
  - 클래스마다 번호 직접 지정 (기본 `0 = sign, 1 = median, 2 = fence`), 또는 "내보내지 않음"
  - 규칙: 번호 겹침 불가, 0부터 빈 번호 없이 (예: 도로표지판만 내보내면 `0 = sign`, `nc = 1`)
  - 내보내지 않는 클래스의 라벨은 빼고, 그 클래스만 있는 이미지는 제외

### 학습에 쓰는 이미지
- 박스 AI: 시설물 이미지 전부 + 배경 이미지(시설물 없음) 시설물 수만큼
- 배경을 시설물 수만큼만 쓰는 이유: 배경이 너무 많을 때 "아무것도 없음" 쪽으로 치우친 학습 방지, 비슷한 장면 반복으로 늘어나는 학습 시간 절약
- 키포인트 AI: 시설물 이미지만 (배경에는 찍을 키포인트 없음)

### 이미지 상태 3가지
- **미작업** (회색): 아직 아무도 안 봄
- **AI 예측 (확인 필요)** (주황, 점선): AI가 그린 것. 사람이 고치고 확정해야 함
- **사람 검수 완료** (초록): 사람이 확정함. 학습과 내보내기에는 이것만 사용

### 프레임 추출 (구간 자르기, 저장 위치)
- **구간 자르기**: 영상을 보면서 쓸 구간의 시작(S)과 끝(E)을 정합니다. 영상 파일은 바뀌지 않습니다.
- **저장 위치**
  - 새 데이터셋 폴더 (기본): 구간이나 간격이 다르면 폴더를 따로 만듭니다. 이름은 자동으로 `영상_시작_끝_간격`
    (예: `dji_0343_1m00s_9m00s_500ms` = 구간 1분 0초 ~ 9분 0초, 0.5초(500ms)마다 1장 / 전체면 `dji_0343_full_500ms`). 장수는 데이터셋 목록에 표시.
    이름은 영문 소문자, 숫자, `_` 만. 한글, 띄어쓰기, 점, `-` 불가 (경로 문제와 확장자 오해 방지). 간격은 정수 초면 `s`, 아니면 `ms`.
  - 지금 연 데이터셋에 추가: 다른 영상을 같은 데이터셋에 넣어 함께 학습할 때. 같은 영상이 이미 있으면 먼저 확인합니다.
- 프레임 번호는 항상 영상 0번 프레임 기준이라, 구간이 달라도 같은 영상, 같은 간격이면 같은 이미지가 나옵니다.

## 라벨링 기준 (모두 4점)

| 키포인트 | 도로표지판 | 중앙분리대 / 무단횡단방지펜스 |
|---|---|---|
| 1 | 밑동 (base): 기둥이 지면에 닿는 곳 | 아래 끝: 박스 아래쪽에서 시설물이 시작되는 곳 (화면 밖으로 이어지면 화면 맨 아래) |
| 2 | 중간 (middle): 기둥 가운데 | 1/3 지점 (실제 시설물 선 위, 휘면 휜 위치 그대로) |
| 3 | 꼭대기 (top): 팔이 시작되는 곳 | 2/3 지점 (실제 시설물 선 위) |
| 4 | 팔 끝 (tip) | 위 끝: 시설물이 기준선과 만나는 곳 |

기준선(노란 점선, 화면 위에서 2/3 높이 = 아래 1/3 경계): 화면에만 표시 (이미지 파일에는 저장 안 됨). 도로표지판은 기준선 아래에 전체가 들어온 것만 라벨링.
중앙분리대, 무단횡단방지펜스 박스: 기준선 아래 부분만 1개 (그리면 위쪽이 기준선에 자동으로 맞춰짐).
키포인트는 1(아래 끝), 4(위 끝)만 클릭하면 2, 3이 일직선 3등분에 자동으로 찍힘 (휘어 있으면 2, 3만 끌어서 수정, L = 다시 일직선 정렬).
이어진 시설물 1개 = 박스 1개 (화면 아래 끝 ~ 기준선, 나눠서 잡지 않기). 중간에 실제로 끊겨 있으면 이어진 덩어리마다 박스 1개.
중앙분리대, 무단횡단방지펜스 키포인트는 윗부분(중앙분리대 상단선, 펜스 상단 난간)에 찍기 (아래쪽, 지면에 닿는 곳에 찍지 않기).
파손 판단: 키포인트 2, 3이 1-4 직선에서 벗어난 정도 = 꺾임/휨, 차로 쪽으로 벗어남 = 차로 침범.

- 안 보이는 점은 S로 건너뜀
- 기준은 `labeler/config.py` 한 곳에서 바꿉니다.

## 단축키

| 키 | 기능 | 키 | 기능 |
|---|---|---|---|
| B | 박스 그리기 | V | 선택/수정 |
| 1 2 3 | 클래스 선택 | S | 키포인트 건너뛰기 |
| R | 키포인트 다시 찍기 | Delete | 객체 삭제 |
| L | 키포인트 2, 3 일직선 정렬 | Shift+Delete | 모든 객체 삭제 |
| Space | 확정하고 다음 | N | 시설물 없음으로 확정 |
| U | 확정 취소 (미작업으로, 박스와 점은 유지) | | |
| A / D | 이전 / 다음 | Ctrl+Z | 되돌리기 |
| 휠 | 확대/축소 | 우클릭 | 누른 채 끌어서 화면 이동 |
| F | 화면 맞춤 | | |

## 코드 구성

```
main.py                  실행
labeler/
  config.py              라벨링 기준 (클래스, 키포인트 이름, 가이드)
  project.py             데이터셋 폴더, 라벨 파일 읽기/쓰기, 진행 현황 (코드 이름은 Project)
  frames.py              동영상 프레임 추출
  add_video.py           영상 추가 (구간 추출 + 빈 라벨)
  ai_box.py              박스 AI (RF-DETR Nano)
  ai_keypoint.py         키포인트 AI (ViTPose)
  assist.py              두 AI 한 번에 학습 / 자동 라벨링
  export.py              YOLO Pose 내보내기 + 증강
  ui/                    화면 (탭별 파일 1개씩)
models/                  AI 시작 가중치 (rfdetr_nano, vitpose_base)
datasets/                데이터셋 폴더들 (데이터셋 1개 = 폴더 1개)
examples/                라벨링 예시 이미지 (클래스별 폴더: sign, median, fence)
raw_data/                원본 영상 (구간 변경 때 영상을 못 찾으면 여기서 같은 이름을 찾음)
```

## 라벨 파일 형식 (`labels/<이미지이름>.json`, 픽셀 좌표)

```json
{"image": "DJI_0342_f002359.jpg", "width": 2688, "height": 1512,
 "status": "human", "background": false, "source": "", "ai_score": null,
 "objects": [{"cls": 0, "box": [x1, y1, x2, y2], "kpts": [[x, y, 2], [x, y, 2], [x, y, 2], [0, 0, 0]], "score": null}]}
```
`kpts`의 세 번째 값: 2 = 보임, 0 = 없음(가려짐/화면 밖)
