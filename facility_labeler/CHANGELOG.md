## 2. 라벨링 탭
- **기준선(노란 점선)**: 화면 위에서 2/3 높이, 이 선 아래(화면 아래 1/3)만 라벨링. 화면에만 표시 (이미지 파일에는 저장 안 됨)
- **중앙분리대, 무단횡단방지펜스**
  - 박스 위쪽 = 기준선 (자동 맞춤), 이어진 시설물 1개 = 박스 1개
  - 키포인트 1(아래 끝), 4(위 끝)만 클릭 → 2, 3은 일직선 3등분에 자동
  - 4번은 기준선 근처(화면 25px 안)를 클릭할 때만 기준선에 맞춤, 시설물이 기준선 전에 끝나면 끝나는 곳에 그대로
    (처음엔 항상 기준선에 강제로 맞춰서, 기준선 전에 끝나는 펜스에서 4번이 위로 올라가던 문제 수정)
  - 키포인트는 시설물 윗부분에: 중앙분리대 상단선, 펜스 상단 난간 (아래쪽, 지면에 닿는 곳에 찍지 않기)
  - **L**: 키포인트 2, 3 일직선 정렬
- 박스 그리기 모드에서도 키포인트, 선택한 박스 모서리 바로 끌어서 수정 (V 불필요)
- 박스를 그리는 동안 박스 안이 색으로 채워지던 문제 수정 (키포인트를 그린 객체가 있을 때)
- **Shift+Delete**: 현재 이미지의 모든 객체 삭제 (Ctrl+Z로 되돌리기)
- **AI 자동 라벨링 칸**
  - 다른 데이터셋 모델 가져오기 버튼
  - 여러 장 한 번에 (3번 탭에서 이동): 대상, 박스 threshold, 진행 막대, 중지. 끝나면 'AI 예측' 보기로 자동 전환
  - **AI 예측 라벨 전체 지우기**: 'AI 예측' 이미지의 객체를 모두 지우고 미작업으로 (사람 검수 완료는 그대로, 이전 라벨은 removed/<날짜>_ai_labels/ 에 복사)
  - 박스 점수와 키포인트 점수 따로 표시 (예: `박스 0.87 / 키포인트 0.89`)
  - "박스를 그리면 키포인트 AI 자동 라벨링" 기본값: 꺼짐
- 용어 통일: "점" → "키포인트", AI 동작은 "AI 자동 라벨링"
- 이미지 목록에 클래스별 객체 수 (예: `객체 2 (표지판 1, 분리대 1)`), 목록 위에 보기, 검수 완료 객체 합계
- **클래스별 보기**: 보기에 '도로표지판 / 중앙분리대 / 무단횡단방지펜스 있는 이미지' 추가 (그 클래스 객체가 1개라도 있는 이미지만)
- 라벨링 기준 칸을 오른쪽 맨 위로, 오른쪽 칸 너비 확대
- **라벨링 예시 이미지**: 라벨링 기준 칸의 '예시 이미지 보기' 버튼, 클래스별 보기, 파일 추가, 지금 라벨링 화면 추가, 삭제 (examples/<클래스>/ 에 저장, 3종 예시 1장씩 등록)

## 전체 검수 후 수정
- **AI 자동 라벨링 보호**: 그 사이 사람이 확정한 이미지는 덮어쓰지 않음 (처리 직전, 저장 직전 두 번 확인)
- **미작업이지만 사람이 그린 객체가 있는 이미지는 AI 자동 라벨링이 지우지 않음** (확정 취소, 저장만 한 이미지)
- 여러 장 자동 라벨링 중에는 확정, 이동, 삭제 버튼과 단축키도 잠금
- 라벨 파일이 없거나 깨진 이미지도 자동 라벨링이 멈추지 않음, 읽을 수 없는 이미지는 건너뜀
- **좌표를 이미지 안으로**: 키포인트, 박스를 이미지 밖에 찍어도 안쪽으로 (이미지 밖 좌표는 YOLO 가 그 이미지를 통째로 버림), 내보내기와 박스 AI 학습 라벨도 한 번 더 확인
- **라벨 저장을 안전하게**: 임시 파일에 다 쓴 뒤 바꿔치기, 깨진 라벨 파일은 미작업으로 취급 (툴이 안 켜지던 문제 방지)
- **작업 중 창 닫기, 새로고침 막기** (프레임 추출, 구간 변경, AI 학습, 자동 라벨링, 내보내기, YOLO)
- **data.yaml 에 절대 경로를 넣지 않음**: 폴더를 옮기거나 팀원 PC 에서도 YOLO 학습 가능, YOLO 모델 목록도 지금 폴더 기준 경로
- 구간 변경, 폴더 이름 변경은 다른 작업 중에는 막음
- 같은 영상을 같은 데이터셋에 다시 넣지 않음 (구간 변경 사용 안내), 영상 추가 때도 근처에 이미 있는 프레임은 다시 뽑지 않음
- AI 가 찾은 중앙분리대, 펜스 박스도 기준선 아래로 맞춤, 현재 이미지 1장 자동 라벨링도 화면의 박스 threshold 사용

- **.gitignore**: 데이터셋(`datasets/`), 원본 영상(`raw_data/`, mp4 등), AI 가중치 파일(100MB 초과), `last_project.json`, `__pycache__` 제외
- README 설치 방법 갱신
- 깃허브 업로드: 팀 레포 `sjh990/ai_dataset_manager` 의 `add-facility-labeler` 브랜치(`facility_labeler/` 폴더), 개인 레포 `sswwd95/facility_labeler` (Private, 이 폴더가 원본)
- `docs/fence_median_compare.jpg` (펜스, 분리대 비교 이미지, 웹 캡처 포함) 는 업로드 제외

## 다른 PC 설치 (어떤 윈도우 PC에서도 설치 가능)
- 새 PC에서 박스 AI 학습 때 `pytorch_lightning` 없음 에러 수정: requirements.txt 의 `rfdetr` → `rfdetr[train]` (학습용 추가 패키지 포함)
- **setup.bat**: 더블클릭 한 번으로 설치 (uv 설치 → `.venv` Python 3.11 → torch CUDA 12.8 → 패키지), `setup.bat cpu` = GPU 없는 PC
- **requirements.txt** 하나로 통합: 라벨링 PC 환경의 모든 패키지 버전 고정 (위쪽 = 직접 쓰는 패키지, 아래쪽 = 하위 패키지, PC마다 같은 버전 설치)
- **tools/check_env.py**: 설치 확인 (패키지 import, GPU 인식)
- run.bat: `.venv` 우선 사용, 없으면 기존 conda 환경 `ai_label`
- `.venv/` 깃허브 제외, `.bat` 파일 줄바꿈 CRLF 고정 (`.gitattributes`)
- README 설치 방법 갱신
- **tools/download_models.py**: AI 시작 가중치 자동 내려받기 (박스 AI, 키포인트 AI, YOLO11n-pose, `--all` = SAM 포함). 받는 주소 고정, 라벨링 PC 파일과 sha256 비교, 있으면 건너뜀
- setup.bat 5단계로: 마지막에 모델 내려받기
- 1번 탭 데이터셋 목록: 폴더가 한 번 더 감싸진 경우(`datasets\datasets\<이름>`, 압축 풀기 폴더)도 인식
- README: VS Code 터미널 실행 방법(`.\setup.bat`), 깨진 uv 경로 표기 수정
- 설치 안내 문구: '아나콘다 필요 없음' → '어떤 윈도우 PC에서도 설치 가능'
